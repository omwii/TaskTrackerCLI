# task-tracker-cli
---
Project URL: https://roadmap.sh/projects/task-tracker

This application can help you add, update, mark, delete and list your tasks (all, or by state). Made completely without AI (bruh).

Commands
---
1. Add: create new task
2. Update: rename existing task
3. Delete: remove task
4. Mark: change task state
5. List: shows all your tasks
